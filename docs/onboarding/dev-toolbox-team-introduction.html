05 / Delivery

Every feature follows a visible loop.

Requirement→Architecture review→Plan→Stitch design→Explicit approval→Implement→Check→PR + preview

Production deployment is outside this workflow. New database work uses a new immutable migration; secrets never enter client code or commits.

11 / Your first contribution

Start small. Keep it traceable.

  • Read README.md, AGENTS.md, and ARCHITECTURE.md.
  • Choose a requirement and check its status and UI-approval state.
  • Run npm ci, then npm run dev; configure persistence only when it is needed.
  • Follow the relevant skill, preserve feature boundaries, and run npm run check.
  • Review scope and secrets, then deliver through a pull request and Vercel Preview.
